# Ansible: Zero to Production

One self-contained learning path for Ansible, from "what problem does configuration management solve" to running Ansible in production with roles, collections, secrets, testing, CI/CD and fleets of many servers.

Start at **[INDEX.md](INDEX.md)**. Topic files are in [`notes/`](notes/), numbered in reading order.

**Status:** ✅ Complete: 68 topics in 13 parts, from configuration-management basics to production (roles, collections, Vault and secret managers, Molecule, execution environments, GitHub Actions/Jenkins, AWX/AAP, scaling, security), with three projects.
**Targets:** ansible-core 2.22 / `ansible` package 15, checked November 2026.
**Every topic has the same shape:** ⚡ Core (10-minute version) · What it is · Why it exists · Analogy · How it works inside · Code / commands (sample output explained) · Hands-on lab · Where you'll use it · When it breaks · Quick recap + interview questions + a scenario question.
**Lab:** Ansible in WSL2 Ubuntu (control node) → Docker containers with SSH + systemd as managed nodes (AlmaLinux 10, Ubuntu 24.04) → one AWS free-tier capstone.
